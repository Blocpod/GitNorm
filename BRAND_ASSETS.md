# GitNorm brand assets

All finished assets below are original generations created for GitNorm. Their
working copies are committed with the product; the full-resolution masters stay
in Codex's generated-image library.

## Primary mark

Saved as `public/brand/gitnorm-mark.png`, `app/icon.png`, and
`app/apple-icon.png`.

Prompt:

> Create an original primary logo mark for a product named GitNorm. Use case:
> app icon, browser favicon, website navigation mark, and social avatar. Core
> idea: a calm, approachable home for personal software—version history,
> safekeeping, and sharing—without looking technical. Symbol: an abstract,
> gently folded repository/shelf form with one subtle branching path integrated
> into the negative space. No literal folder, no padlock, no cloud, no code
> brackets. Style: award-worthy premium industrial-design restraint; minimal,
> warm, quietly confident, exquisitely resolved geometry; soft dimensionality
> like satin ceramic and anodized metal; original identity, not derivative of
> any existing technology company. Composition: one centered symbol only,
> square canvas, generous clear space, visually balanced, readable and
> distinctive at 24 px. Palette: near-black graphite, warm ivory, restrained
> mint, and one tiny citrine accent. High contrast without neon.
> Lighting/material: controlled studio lighting, soft tactile depth, crisp
> silhouette, no photorealistic environment. Background: transparent. Avoid:
> any text, letters, monograms, Apple logo, GitHub logo, Octocat, stock-icon
> appearance, clip art, generic gradient blob, device mockup, watermark,
> border, badge, busy detail.

## Project avatars

Saved as `public/icons/project-orbit.png`,
`public/icons/project-sprout.png`, `public/icons/project-prism.png`, and
`public/icons/project-wave.png`.

Each avatar used this shared direction: an original project-avatar icon for
GitNorm's built-in visual system; premium minimal industrial design in the same
satin-ceramic and anodized-metal family; rounded, tactile, quiet, precise, and
friendly; one compact centered emblem, almost front-facing with subtle depth;
square canvas with generous transparent padding; unmistakable at 32 px;
graphite, warm ivory, muted mint, and a tiny citrine focal point; no text,
letters, Apple or GitHub marks, stock icons, emoji, sticker outlines, badge
backgrounds, scenes, mockups, watermarks, or excess detail.

The concept-specific prompt for Orbit was a tiny warm citrine sphere traveling
through two calm mint-and-ivory curved bands held by a graphite frame, suggesting
an idea in motion. Sprout used two softly folded mint leaves emerging from a low
warm-ivory cradle, joined by a tiny citrine pivot, suggesting a useful idea
growing into a personal app. Prism used three rounded triangular ceramic planes
nesting into a compact open form, graphite outside and warm ivory/mint inside,
joined by one tiny citrine bead. Wave used two calm interlocking ribbon waves,
one warm ivory and one muted mint, flowing through a compact graphite cradle
and meeting at a tiny citrine node.

## Social preview

Saved as `public/og.png`.

Prompt:

> Create exactly one cohesive, premium-minimal branded social-preview image for
> GitNorm, positioned as “GitHub for normies”: a calm, friendly home for
> personal software with effortless safekeeping, version history, and sharing.
> Landscape 1200×630-ish ratio with generous warm-ivory negative space and a
> quiet editorial studio atmosphere. Show a single elegant abstract
> repository/home object built from a few layered horizontal shelves or softly
> offset archival trays, suggesting safekeeping and version history. Integrate
> one subtle branching seam across the layers and one tiny citrine anchor
> detail. Use refined 3D product-design still-life styling, satin ceramic,
> anodized graphite metal, muted mint, soft diffuse studio light, and gentle
> shadows. Keep the object to one side and typography in a spacious field.
> Render exactly: title “GitNorm” and supporting copy “A home for the software
> you make.” Use refined modern sans-serif typography and no other text. Avoid
> Apple marks, GitHub marks, Octocat, code symbols, angle brackets, terminal
> symbols, stock imagery, people, extra captions, watermarks, UI screenshots,
> busy gradients, neon colors, glossy plastic, and clutter.
